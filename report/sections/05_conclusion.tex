This project developed a computer vision pipeline for analyzing ski jumping videos, starting from raw broadcast footage and producing a stabilized trajectory of the athlete. The final system combines jumper detection, segmentation-based center-of-mass estimation, Kalman filtering, shot-aware camera-motion estimation, and geometric reconstruction of the visible slope. The experiments show that the 2D part of the pipeline is reasonably robust: the athlete can be detected across different shots, the trajectory can be stabilized in a selected reference frame, and unreliable motion estimates can be filtered using the propagated transformation confidence.

The most challenging part of the project is the metric reconstruction of the scene. In principle, the reconstructed slope and the lifted trajectory can provide a much richer description than a simple image-space curve. In practice, however, this stage is strongly affected by camera calibration and by the amount of reliable geometric information visible in the frame. The experiments showed that estimating the whole intrinsic matrix \(K\) from the available scene constraints is often unstable. Constraining the principal point to the image center improves the behavior, but the reconstruction is still not guaranteed to have correct real-world scale or perfectly reliable orientation.

A first important improvement would be to introduce at least one known real measurement in the scene. For example, knowing the actual distance between two visible points, the width of a track element, or the physical distance between two markings would allow the reconstruction to be scaled in metric units. This would make it possible to express the trajectory in real dimensions instead of only in an arbitrary reconstructed scale.

A second improvement would be to use a camera that is already calibrated, especially for the shot where the jumper is in flight. This part of the video is the most important for trajectory analysis, but it also contains very few stable reference points that can be used to build geometric constraints. Having the intrinsic parameters available in advance would remove one of the main sources of instability and would make the 3D lifting step more reliable.

Finally, if real scale were available, the different local reconstructions could be combined into a single consistent model. At the moment, each reconstructed segment is tied to its own selected frame and calibration assumptions. With metric scale and better camera calibration, the reconstructed inrun, flight, and landing portions could be aligned in the same coordinate system, producing a more complete 3D representation of the jump and enabling more meaningful measurements of the athlete's motion.
